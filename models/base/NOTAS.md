# Base v0 — media de 14 días

**Qué hace:** para cada tienda×familia, predice los 16 días siguientes con la media de los últimos 14 días.

**Por qué empezar así:** una línea base tonta pero honesta nos dice cuánto vale cada idea posterior.
Si un LightGBM con 50 variables no gana a esto, algo está mal (casi siempre, una fuga o un bug).
